# Project Overview

DBeaver Community is a free and open-source database management tool designed for developers, database administrators, analysts, and other users who work with relational and other database systems.

It provides a graphical environment for connecting to databases, browsing schemas and tables, writing SQL queries, editing data, managing database objects, creating diagrams, and transferring data between different sources.

The application is based on the Eclipse platform and supports a wide range of database technologies through its integrated and extensible driver system.

The latest stable 2026 release is **DBeaver Community 26.2.1**, released on September 21, 2026.

---

# Database Management & SQL Editor

DBeaver provides a database navigator for browsing connections, schemas, tables, views, procedures, functions, indexes, constraints, and other database objects.

The SQL Editor supports syntax highlighting, code completion, multiple SQL consoles, parameters, query execution, and result visualization.

SQL scripts can be organized into projects and executed against configured database connections. Query results can be inspected through the data editor and exported using supported formats.

DBeaver supports numerous database systems through dedicated drivers, making it possible to manage different technologies from a single interface.

---

# Data Editor & Database Objects

The Data Editor provides a graphical interface for viewing and modifying table records.

Users can filter, sort, search, and edit database values directly through the result grid where the connected database and permissions allow such operations.

Metadata editors provide graphical controls for working with tables, columns, indexes, keys, constraints, views, procedures, and other supported objects.

The application also provides tools for generating and viewing SQL definitions for database objects.

---

# ER Diagrams & Database Visualization

DBeaver includes diagram tools for visualizing database structures and relationships.

Entity-relationship diagrams can display tables, columns, keys, and relationships, making them useful for understanding existing database schemas.

Diagram layouts can be adjusted to improve readability when working with large database structures.

The 2026 releases include fixes and improvements for relationship handling and diagram editing.

---

# Data Transfer & Import / Export

DBeaver provides data-transfer tools for moving information between database tables and other supported data sources.

Users can configure import and export operations and select supported formats according to their workflow.

The data-transfer system can be used for database migrations, backups, development datasets, reporting, and moving data between compatible systems.

The 26.x releases also include improvements to CSV import and export, including better handling of large CSV files and multi-character delimiters and quotes.

---

# AI Assistant & 2026 Features

DBeaver 26.x introduced additional AI-assisted database workflows.

The AI Assistant can help generate SQL queries and answer questions about database-related tasks. AI-generated SQL should be reviewed before execution because generated queries can contain mistakes.

In DBeaver Community 26.2.1, OpenAI AI subscriptions were added, AI preferences were reorganized, and AI-generated SQL scripts gained regular SQL-console execution with result tabs, progress tracking, and error-fixing capabilities.

DBeaver 26.1 also added support for newer OpenAI Codex models through GitHub Copilot.

---

# Connectivity & Supported Platforms

DBeaver Community is available for Windows, macOS, and Linux. Official downloads include x86 and ARM builds for supported platforms.

The application can connect to many database technologies through its driver system, allowing users to maintain multiple database connections within the same workspace.

Connection profiles can store server addresses, ports, database names, authentication settings, and other connection parameters.

Credentials should be protected and only stored on trusted systems.
